# ChatGPT Prompt Testing Repository

## Overview

This repository serves as a sandbox for managing and organizing prompt definitions and related documentation used in ChatGPT experiments. It is not a codebase but a structured environment to develop, test, and refine prompts for various use cases.

## Structure

- `docs/`: Contains reference text files such as examples, TAP schema, column information, and other supporting materials.
- `prompt/`: Contains evolving versions of prompt definitions (`v1.txt`, `v2.txt`, `v3.txt`, etc.) used for iterative testing and improvement.

## Purpose

The primary purpose of this repository is to provide a centralized location to store and track prompt variations and relevant documentation, facilitating efficient experimentation and development with ChatGPT.
