Translate ADQL to URLs for tap_obs and tap_cat:

- tap_obs examples

Example ADQL: 

SELECT DISTINCT instrument_name
FROM ivoa.ObsCore
WHERE facility_name LIKE '%VLT%'
ORDER BY instrument_name

Translates to:  

https://archive.eso.org/tap_obs/sync?REQUEST=doQuery&FORMAT=txt&LANG=ADQL&MAXREC=200&QUERY=SELECT+DISTINCT+instrument_name%0D%0AFROM+ivoa.ObsCore%0D%0AWHERE+facility_name+LIKE+%27%25VLT%25%27%0D%0AORDER+BY+instrument_name%0D%0A

- tap_cat examples

Example ADQL (this query returns the most recent version of any catalog): 

SELECT schema_name, collection, table_name, title, version
FROM TAP_SCHEMA.tables
WHERE cat_id in 
             (select t1.cat_id cat_id 
              from TAP_SCHEMA.tables t1
              left outer join TAP_SCHEMA.tables t2 on (t1.title = t2.title and t1.version< t2.version) 
              where t2.title is null)
ORDER BY schema_name, collection, title

Translates to:  

https://archive.eso.org/tap_cat/sync?REQUEST=doQuery&LANG=ADQL&MAXREC=200&FORMAT=text&QUERY=SELECT%20schema_name,%20collection,%20table_name,%20title,%20version%0aFROM%20TAP_SCHEMA.tables%0aWHERE%20cat_id%20in%0a%28select%20t1.cat_id%20cat_id%0afrom%20TAP_SCHEMA.tables%20t1%0aleft%20outer%20join%20TAP_SCHEMA.tables%20t2%20on%20%28t1.title%20=%20t2.title%20and%20t1.version%3c%20t2.version%29%0awhere%20t2.title%20is%20null%29%0aORDER%20BY%20schema_name,%20collection,%20title
