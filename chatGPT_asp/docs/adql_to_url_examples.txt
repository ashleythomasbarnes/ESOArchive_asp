Example ADQL (simple): 

SELECT DISTINCT instrument_name
FROM ivoa.ObsCore
WHERE facility_name LIKE '%VLT%'
ORDER BY instrument_name

Example ADQL (Find UVES 1d spectra for objects also observed by MUSE): 

SELECT DISTINCT uves.obs_id, uves.target_name, uves.s_ra, uves.s_dec, uves.access_url
FROM ivoa.ObsCore AS uves
JOIN ivoa.ObsCore AS muse
  ON 1 = INTERSECTS(uves.s_region, muse.s_region)
WHERE uves.instrument_name LIKE '%UVES%'
  AND uves.dataproduct_type = 'spectrum'
  AND uves.calib_level >= 1
  AND muse.instrument_name LIKE '%MUSE%'
  AND muse.dataproduct_type = 'cube'

https://archive.eso.org/tap_obs/sync?REQUEST=doQuery&LANG=ADQL&MAXREC=200&FORMAT=txt&QUERY=SELECT%20DISTINCT%20uves.obs_id,%20uves.target_name,%20uves.s_ra,%20uves.s_dec,%20uves.access_url%0aFROM%20ivoa.ObsCore%20AS%20uves%0aJOIN%20ivoa.ObsCore%20AS%20muse%0aON%201%20=%20INTERSECTS%28uves.s_region,%20muse.s_region%29%0aWHERE%20uves.instrument_name%20LIKE%20%27%25UVES%25%27%0aAND%20uves.dataproduct_type%20=%20%27spectrum%27%0aAND%20uves.calib_level%20%3e=%201%0aAND%20muse.instrument_name%20LIKE%20%27%25MUSE%25%27%0aAND%20muse.dataproduct_type%20=%20%27cube%27
